# 🌙 رحلة اسطنبول — React + Vite + Tailwind

موقع شخصي كامل لرحلة اسطنبول (6 أيام — زوجين، سكن في السلطان أحمد).

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # نسخة إنتاجية في dist/
```

## بنية المشروع

```
src/
  data.js              ← كل المحتوى هنا (أيام، معالم، مطاعم، نصائح)
  hooks.js             ← useWikiImage: يسحب صور المعالم من ويكيبيديا
  components/
    Nav.jsx            شريط التنقل
    Hero.jsx           الهيدر + العدّاد التنازلي
    Days.jsx           برنامج الأيام الستة (تبويبات + خط زمني)
    Cards.jsx          أقسام المعالم والمطاعم (بطاقات بالصور + فلاتر)
    Tips.jsx           البدائل الاختيارية + النصائح
    WikiImage.jsx      مكوّن الصور (تحميل + بديل عند الفشل)
    Footer.jsx         الفوتر + زر الأعلى
```

## الصور

الصور تُسحب تلقائياً من ويكيبيديا عبر `pageimages API` — كل عنصر في `data.js`
فيه حقل `wiki` = عنوان المقال الإنجليزي. لتغيير صورة مكان، غيّر قيمة `wiki`.
لو ما توفرت صورة تظهر بطاقة متدرجة مع الأيقونة.

## التعديل

| تبغى تعدل | دور على |
|---|---|
| تاريخ الرحلة (العدّاد) | `TRIP_DATE` في `src/data.js` |
| برنامج يوم | مصفوفة `DAYS` |
| معلم / مطعم | `PLACES` / `RESTAURANTS` |
| الألوان والخطوط | `@theme` في `src/index.css` |
